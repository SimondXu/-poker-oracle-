# Table UI v2 (superseded)

Status: superseded. The current visual system is "Card-Room Print", documented in `apps/web/DESIGN.md` (tokens, rules, components) with a sidecar at `apps/web/.impeccable/design.json`. Slot wiring and the code-level contract are in `apps/web/src/features/game/components/README.md`.

History:
- This note was the PokerNow-flat v2 spec: flat green felt, grey rail, white plates, yellow chip bubbles, a flat dark-charcoal page, and a `#2f8f46` felt.
- It replaced the earlier "Private Room" look (navy and gold glow, wood rail, glassmorphism).
- The v2 build was done on `feat/pokernow-ui`, then redesigned in Oct 2026 as Card-Room Print: an ink-navy ramp, baize felt with a guilloche, one vermilion ink, ivory card stock, and a condensed index face.
- Product goal unchanged: inspired by PokerNow's clarity (big readable cards, bets between seat and pot, fixed action slots), but more beautiful.
